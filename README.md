# FR Engenharia Civil

Site institucional de alta conversão da FR Engenharia Civil e Avaliações.

## Stack

- Next.js + TypeScript
- Formulário de diagnóstico gamificado
- Painel de leads protegido por senha
- Persistência com Neon Postgres quando `POSTGRES_URL` estiver configurada

## Operação

O projeto é implantado automaticamente na Vercel a partir da branch `main`. As credenciais do painel são armazenadas exclusivamente como variáveis criptografadas de ambiente na Vercel.
